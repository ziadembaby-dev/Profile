# Personal Profile

A simple personal profile webpage created as my first HTML assignment.

The main goal of this project was to practice the fundamentals of HTML, with a focus on using **tables** and **forms** to structure and organize webpage content.

## 📌 About The Project

This project is a basic profile page that contains personal information and form elements.

It was created as a practical exercise to understand how HTML elements work together to build a structured webpage.

## 🎯 What I Practiced

* HTML document structure
* Headings and paragraphs
* Images and links
* Tables
* Forms and form elements
* Using tables to arrange elements next to each other
* Basic HTML page organization
